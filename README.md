# Fue Canónico · sitio web

Sitio de presentación de la banda. Es una sola página: todo el diseño, las animaciones y los shaders están en `index.html`, y las imágenes en `img/`.

## Verlo en vivo

1. Abrí esta carpeta en VS Code (Archivo > Abrir carpeta).
2. Instalá la extensión **Live Server** (de Ritwick Dey) si no la tenés.
3. Clic derecho sobre `index.html` > **Open with Live Server**.
4. Cada vez que guardes un cambio, la página se recarga sola.

## Dónde está cada cosa en `index.html`

- **Portada** (pasto, logo, géneros): busca `1 · the meadow`.
- **Primer EP** (Greta): busca `2 · the EP`.
- **Canciones** (fondo líquido): busca `3 · songs`. Los colores están en `CONFIG` (`top` = Flor en el Mar, `bottom` = La Pared) y la velocidad en `speed`.
- **Nosotros** (foto en el pasto): busca `4 · the five of them`.
- **Contacto**: busca `5 · contact`.

## Imágenes

| Archivo | Uso |
| --- | --- |
| `img/campo.webp` | Fondo de la portada |
| `img/logo.webp` | Logo fue CANÓNICO |
| `img/personitas.webp` | Logo de las personitas (esquina) |
| `img/ep.webp` | Greta con las flores (Primer EP) |
| `img/banda.webp` / `img/banda-movil.webp` | Foto de la banda (compu / celular) |
| `img/flor-luz.webp` / `img/flor-rosa.webp` | Flores desenfocadas decorativas |

Todas las imágenes están en WebP para que el sitio cargue más rápido. Los `.jpg` y `.png` que quedan en `img/` son las versiones anteriores y ya no se usan: se pueden borrar.
